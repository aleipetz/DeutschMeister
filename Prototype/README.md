# Deutsch Meister — German Vocabulary Trainer

A standalone, offline, gamified German vocabulary trainer. English-speaking learner,
minimal grammar, heavy focus on nouns/adjectives/verbs and especially phrasal &
composite (separable-prefix) verbs — the distinctively German pattern. Runs as one
self-contained HTML file, no install, no server, no account, no data leaving your
computer.

## Quick start

Just open the app:

```bash
open dist/german-vocab.html
```

That's it — double-click works too. Progress is saved in your browser's
`localStorage`, scoped to that file. Use **Settings → Export progress** periodically
to back it up as a `.json` file (also lets you move progress to another machine).

## How it's organized

```
Content/    — the vocabulary itself: plain JSON, organized by CEFR level (A1-C2)
              and part of speech. This is the "database." See Content/schema/SCHEMA.md.
App/        — hand-edited app source (HTML/CSS/JS). Open App/index.html directly
              in a browser for development (it reads App/data.js, regenerated by
              the build script, so it always reflects current content).
dist/       — the single-file build. dist/german-vocab.html is what you actually use.
Tools/    — validate_content.py, build.py, stats.py — all plain Python, no deps.
Tests/      — engine.test.js — plain Node test for the SRS/gamification logic.
Docs/       — architecture notes, the content progress tracker, gamification design.
```

## Development workflow

After editing anything in `Content/data/`:

```bash
python3 Tools/validate_content.py   # must pass before content counts as "done"
python3 Tools/stats.py              # regenerates verb-families.json + prints coverage
python3 Tools/build.py              # regenerates App/data.js and dist/german-vocab.html
```

After editing `App/engine.js` (spaced-repetition or gamification logic) or
`App/quiz.js` (quiz question generation):

```bash
node Tests/engine.test.js
node Tests/quiz.test.js
```

`Docs/content-progress-tracker.md` tracks what content batches are done vs. pending —
read it first when picking up content work in a new session.

## Design at a glance

- **Spaced repetition**: 7-box Leitner system (see `Docs/spaced-repetition-design.md`
  — actually folded into `App/engine.js` + `Docs/gamification-design.md`).
- **Gamification**: XP, levels, streaks with freezes, in-session combo multiplier,
  achievement badges. See `Docs/gamification-design.md`.
- **Voiceover**: browser-native Web Speech API (`App/speech.js`), German voice,
  no network dependency.
- **Storage**: `localStorage` only, namespaced under `germanVocab.v1`. No backend.
